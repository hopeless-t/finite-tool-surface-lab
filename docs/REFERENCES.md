## Tool-surface / routing

1. **Toollery: Scaling LLM Agents to Thousands of Skills and Tools**  
   Xiangxi Tian, Ran Guan. arXiv:2609.22218 (2026).  
   https://arxiv.org/abs/2609.22218  
   Code: https://github.com/XiangxiTian/toollery

2. **How Many Tools Should an LLM Agent See? A Chance-Corrected Answer**  
   Vyzantinos Repantis et al. arXiv:2605.24660 (2026).  
   https://arxiv.org/abs/2605.24660

3. **SkillRouter: Retrieve-and-Rerank Skill Selection for LLM Agents at Scale**  
   YanZhao Zheng et al. arXiv:2603.22455 (2026).  
   https://arxiv.org/abs/2603.22455  
   Code: https://github.com/zhengyanzhao1997/SkillRouter

4. **RAG-MCP: Mitigating Prompt Bloat in LLM Tool Selection via Retrieval-Augmented Generation**  
   Tiantian Gan, Qiyao Sun. arXiv:2505.03275 (2025).  
   https://arxiv.org/abs/2505.03275

5. **Scalable LLM Agent Tool Access in the Cloud**  
   Mingxin Li et al. arXiv:2607.15593 (2026).  
   https://arxiv.org/abs/2607.15593

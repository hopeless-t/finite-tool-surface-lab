# Research Questions

## RQ-001 — Surface size
Does Worker performance remain monotonic as visible tool count grows after required tools are already present?

## RQ-002 — Adaptive depth
Can per-query shortlist depth dominate one global fixed-k?

## RQ-003 — Distractor topology
Which distractors are most harmful: random, same-category, description-near, schema-near, aliases, deprecated alternatives, or misleading metadata?

## RQ-004 — Representation
Which fields are needed for routing: name, description, schema, examples, full skill/tool body, qualification metadata?

## RQ-005 — No-tool behavior
How does surface size affect false invocation when the correct action is to use no tool?

## RQ-006 — Multi-tool tasks
How does the sufficient surface change when a task requires a set of tools rather than one tool?

## RQ-007 — Worker capability
Does the optimum surface depend on Worker/model/provider strength?

## RQ-008 — Economics
When does retrieval/reranking cost more than the prompt/inference cost it saves?

## RQ-009 — Dynamic registries
How robust are policies to tool addition, removal, version drift, aliases, and qualification changes?

## RQ-010 — MVCA transfer
Can a surface governor project qualified Warehouse capability into a bounded Worker surface without changing authority semantics?

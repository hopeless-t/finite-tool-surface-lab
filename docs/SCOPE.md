# Scope

## In scope

- active tool-surface size;
- candidate compression;
- adaptive shortlist depth;
- distractor topology;
- tool representation ablation;
- no-tool abstention;
- multi-tool coverage;
- retrieval/reranking economics;
- Worker selection conditional on a fixed surface;
- reproducible public benchmark adapters;
- MVCA transfer analysis.

## Out of scope for the initial phases

- production MCP gateway implementation;
- automatic Tool installation;
- Tool qualification itself;
- authorization policy;
- direct mutation of MVCA Mainline;
- training a large new model before simpler baselines are exhausted;
- private benchmark results as sole canonical evidence.

## Boundary

This repository studies **what capability should be visible**.

It does not decide **what capability is authorized to execute**.

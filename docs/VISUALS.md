# Visual Documentation

Visuals reduce comprehension cost; they do not grant research authority.

Recommended figures:

1. Tool Surface Frontier — success/coverage vs visible tool count or serialized exposure.
2. Surface response curve — metric vs k with confidence intervals.
3. Distractor stress map — overlap/distractor type vs degradation.
4. Representation ablation — routing performance by exposed fields.
5. No-tool false invocation curve — false call rate vs surface size.

Rules:

```text
Figure != Evidence
Pretty Pareto Curve != Causal Proof
One Model != Universal Worker Behavior
```

Canonical claims must be backed by structured metrics and per-task evidence.
